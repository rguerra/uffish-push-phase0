# uffish-push-phase0

Throwaway device spike for Uffish Web Push (bead obsidian-uffish-j6bzz.2):
can one iOS home-screen web app hold two push subscriptions made against two
different VAPID keys, in two service-worker scopes, and do both deliver?

The page holds only two VAPID **public** keys. See RUNBOOK.md for the checks.
Delete this repo once the spike is recorded.
