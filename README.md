# uffish-push-phase0

Throwaway device spike for Uffish Web Push (bead obsidian-uffish-j6bzz.2):
can one iOS home-screen web app hold several push subscriptions, each made
against its own VAPID key in its own service-worker scope (one per vault:
pack-qa-push, uffish-debug, a test vault), and do they all deliver?

The page holds only VAPID **public** keys. See RUNBOOK.md for the checks.
Delete this repo once the spike is recorded.
